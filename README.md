# Smart Vending Machine Simulator

## Description
A Smart Vending Machine Simulator developed using Python and Object-Oriented Programming (OOP). It simulates real-world vending machine operations, including product selection, purchasing, inventory management, and a loyalty points system for registered customers.

## Features
- Display available products and prices.
- Select products and simulate purchases.
- Manage product inventory.
- Support guest and registered customers.
- Reward registered customers with loyalty points.

## Technologies Used
- Python
- Object-Oriented Programming (OOP)
- Streamlit
- Jupyter Notebook

## Learning Outcomes
- Practiced OOP concepts in Python.
- Improved problem-solving and programming skills.
- Learned to implement customer management and inventory handling.

## Project Purpose
To simulate the basic operations of a real-world vending machine through a simple and user-friendly application.
